# Bili-PiP Caption (B站悬浮字幕)

**Bili-PiP Caption** 是一款专为 Bilibili 网页端设计的**全透明、系统级置顶悬浮字幕插件**。
无论你是在边看视频边敲代码，还是在玩全屏游戏，它都能将 B 站的 CC 字幕提取出来，化作一行透明、无边框的沉浸式文字，永远悬浮在屏幕最上层。

---

## ✨ 核心特性

- **🌌 沉浸式全透明无边框**：纯净的文字悬浮体验，没有任何难看的系统边框或背景黑块。
- **🤖 全自动生命周期管理**：在 B 站播放器下方一键开关。打开视频自动启动，离开视频页面（或关闭浏览器）自动销毁，无需手动管理后台进程。
- **⚡ 超低延迟与精准同步**：不依赖语音识别或消耗 CPU 的重计算，纯提取官方弹幕/字幕文件时间轴，与 `<video>` 标签底层时间实现毫秒级硬件同步。
- **🖱️ 防误触智能交互机制**：平时鼠标事件 100% 穿透字幕，不影响你操作底下的任何软件；**右键点击字幕**即可唤出操作面板，支持随意拖拽位置、无极调节字号和颜色。
- **🚀 一键无脑安装配置**：内置自动化 `.bat` 部署脚本，小白也能一键完成 Electron 依赖安装与 Windows 注册表 Native Messaging 绑定。

---

## 🛠️ 系统架构与工作原理

本项目采用 **Chrome Extension (Manifest V3) + Electron** 的混合架构，解决了浏览器端 API 无法实现“跨软件系统级置顶无边框透明窗口”的痛点。

1. **主世界网络拦截 (`interceptor.js`)**：
   由于 Manifest V3 限制了后台直接读取 Response Body，插件通过向网页的主世界注入拦截器，静默拦截 B 站 `.bcc` 或 `.json` 格式的字幕文件请求，提取时间轴并跨世界回传。
2. **生命周期接管 (`background.js` & Native Messaging)**：
   利用 Chrome 的 Native Messaging 技术，浏览器扩展作为父进程，直接拉起并接管 Electron 子进程（`host.js` 代理层）。彻底摆脱系统托盘图标，实现“随看随启，随关随毁”。
3. **高频流式通信 (WebSocket)**：
   为避免 Native Messaging 处理高频长字符串时的阻塞，采用了 `WebSocket (18520 端口)` 进行实时字幕流传输。
4. **Electron 渲染层 (`overlay/`)**：
   使用 `transparent: true` 和 `frame: false` 构建纯文字窗口。利用 IPC 通信与底层指针捕获 (Pointer Capture) 技术，完美避开了 Windows 系统下透明窗口的拖拽和点击穿透 Bug。

## 📦 安装与部署指南

### 环境要求
- Google Chrome 浏览器
- Node.js 环境 (用于运行 Electron)
- Windows 操作系统 (针对透明窗口与 Native Messaging 进行了深度适配)

### 第一步：加载 Chrome 扩展
1. 打开 Chrome 浏览器，进入扩展管理页面 `chrome://extensions/`
2. 开启右上角的 **“开发者模式”**
3. 点击 **“加载已解压的扩展程序”**，选择本项目的根目录。
4. 加载成功后，记住该扩展的 **ID（一串英文字母）**。

### 第二步：一键配置本地环境
1. 在项目根目录下，双击运行 **`一键安装配置.bat`**。
2. 脚本会自动为你下载所需的底层环境（`npm install`）。
3. 按照黑色终端窗口的提示，将刚才在 Chrome 里看到的 **扩展 ID** 粘贴进去并回车。
4. 出现“配置完成”提示后，按任意键退出，并**彻底重启 Chrome 浏览器**。

## 🎮 使用说明

1. **开启字幕**：
   打开任意一个带有 CC 字幕的 B 站视频，在视频播放器下方的工具栏（点赞、投币旁边）会多出一个 **「字幕悬浮」** 按钮。点击它，字幕悬浮窗就会自动出现在屏幕上。
2. **调节大小与颜色 / 拖动位置**：
   将鼠标移动到屏幕上的字幕文字处，**点击「鼠标右键」**，上方会弹出操作菜单。
   - 按住最左侧的 **「⠿ 移动」** 按钮即可在全屏幕随意拖拽。
   - 点击 **A-** / **A+** 调节字号，点击调色板更改字幕颜色。
3. **关闭菜单**：
   调整满意后，点击菜单最右侧的红色 **「✖」** 按钮即可隐藏菜单，窗口将恢复鼠标穿透状态。
4. **关闭字幕**：
   再次点击 B 站网页上的「字幕悬浮」按钮，或者直接关闭/离开该视频网页，悬浮窗都会自动关闭。

## 🐛 技术深坑与解决方案记录（写给开发者）

在开发本项目的过程中，我们解决了大量 Windows + Electron 的底层 Bug：
- **Electron 缩放 Bug (`setPosition` 漂移)**：在开启了 Windows 屏幕缩放 (DPI > 100%) 时，连续调用 `setPosition` 会因为浮点数精度截断导致无边框窗口的宽高不断膨胀拉长。**解决**：在初始化时缓存宽高，拖拽时使用 `setBounds` 锁死固定尺寸。
- **透明窗口无法触发鼠标事件 (`forward: true` 局限性)**：Windows 原生 API 不会将鼠标事件派发给 Alpha=0 的透明像素。**解决**：放弃悬浮触发，将字幕文本 `pointer-events` 设为 `auto` 并绑定 `contextmenu`（右键点击）作为唯一触发源，同时结合 `mainWindow.setIgnoreMouseEvents` 动态控制点击穿透。
- **原生拖拽失效 (`-webkit-app-region: drag`)**：在 `focusable: false` 的窗口中，Windows 会因为防抢焦机制直接丢弃原生拖拽消息。**解决**：重写拖拽引擎，使用 JS 层的 `pointerdown` + `setPointerCapture` 实现全局捕获与 IPC IPC坐标同步，极其丝滑。
- **Chrome Native Messaging 的 stdio 严格要求**：如果直接将 `electron.exe` 设为 NM 主机，Electron 启动时的 GPU 日志会污染标准输出流（stdout），导致 Chrome 判定协议失败并瞬间击杀进程。**解决**：编写了一个极简的 Node.js 脚本 `host.js` 作为“防火墙代理”，由代理负责与 Chrome 进行规范通信，同时以 `stdio: 'ignore'` 参数干净地拉起 Electron。
